# JobConnect 

A scalable, full-stack job portal built with the MERN stack designed to efficiently connect job seekers and recruiters. JobConnect streamlines the hiring process by providing tailored dashboards, secure authentication, and advanced search functionalities.

## ✨ Features

*   **Role-Based Access Control:** Customized dashboards for Candidates, Recruiters, and Administrators.
*   **Secure Authentication:** Robust user authentication and authorization.
*   **Job Management:** Streamlined workflow for recruiters to post, edit, and track job listings.
*   **Advanced Search:** Job seekers can easily filter and search for roles based on specific criteria.
*   **Application Tracking:** Seamless tracking of application statuses for both applicants and employers.
*   **Responsive UI/UX:** A clean, modern, and mobile-friendly interface.

## 🛠️ Tech Stack

*   **Frontend:** React.js, HTML5, CSS3, JavaScript
*   **Backend:** Node.js, Express.js
*   **Database:** MongoDB
*   **Tools:** Git, GitHub, VS Code

## 🚀 Getting Started

Follow these instructions to set up the project locally on your machine.
